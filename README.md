# BrushApp

**Kirim pesan, tanpa ribet.**

BrushApp is a lightweight Android messaging app project focused on text-only conversations.

## Current milestone
- Initial dark-mode chat-list UI
- Android Kotlin + Jetpack Compose project scaffold
- GitHub Actions workflow to build and upload a debug APK
- Demo chat rows only; messaging is not connected yet

## Build APK
Open **Actions → Build BrushApp APK** and download the artifact named **BrushApp-debug** after the workflow succeeds.

Firebase realtime messaging, user accounts, contacts, and notifications will be added in later milestones.
